# Treino Diário Android

Aplicativo Android offline para um programa guiado de 12 semanas de treino do assoalho pélvico masculino.

## Build
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- Java 17
- compileSdk/targetSdk 35
- minSdk 26

O GitHub Actions compila e valida o APK automaticamente.

## Privacidade
Os dados de treino ficam somente no aparelho. O projeto não envia histórico, avaliações ou dados pessoais para servidores externos.
